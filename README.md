# DevPath

## О проекте
Приложение для планирования и контроля процесса обучения.

## Основные возможности
- Создание учебного направления;
- Добавление задач;
- Указание названия, описания и статуса задачи;
- Отметка задач как выполненных;
- Просмотр прогресса;

## Технологический стек

### Frontend
- React;
- TypeScript;
- Vite;
- React Router;
- Vitest и React Testing Library;

### Backend
- Java;
- Spring Boot;
- Spring Security;
- Spring Data JPA;
- Maven;

### База данных
- PostgreSQL;

### Тестирование
- JUnit 5;
- Mockito;
- Интеграционные тесты;

### Инфраструктура
- Docker;
- GitHub Actions (CI/CD);

### Дополнительные технологии
- Redis — кеширование;
- Apache Kafka — асинхронная обработка событий;
- Prometheus — сбор метрик и мониторинг;
- Nginx — веб-сервер и обратный прокси;
- Kubernetes — оркестрация контейнеров;
